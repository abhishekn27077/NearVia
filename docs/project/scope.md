# NEARVIA Project Scope

## 1. Core Problem Statement

Getting a full-time job can take weeks or months, but everyday expenses cannot wait. Simultaneously, local businesses, contractors, shops, and individuals frequently face urgent, short-duration tasks or temporary staffing shortages that do not require permanent hires.

NEARVIA bridges the gap between **Permanent Employment** and **Immediate, Short-Duration, Flexible Work**.

## 2. In-Scope Work Models

- **Micro-Tasks**: 1-2 hours (e.g. unload boxes, assemble furniture, event staging).
- **Short Shifts**: 3-6 hours (e.g. restaurant helper, warehouse rush cover).
- **Half-Day & One-Day Work**: Dedicated single-day engagements.
- **Temporary Replacements**: Immediate cover for absent staff.
- **Skilled Local Tasks**: Local technicians, electricians, plumbers, carpenters, tutors.
- **Daily-Wage Work**: Local daily wage tasks with rapid completion payout records.

## 3. Core Operating Parameters

- **Geographic Radius**: Default ~5 km (max 15 km).
- **Availability**: "Available-Now" real-time status indication.
- **Two-Sided Matching**: Workers discover jobs; Job providers discover qualified available workers.
- **Explainable Matching**: Deterministic multi-factor scoring (Skill, Distance, Availability, Rating).
- **Assisted Onboarding**: Optional verified Agent network to support low-digital-literacy workers.

## 4. Explicit Non-Goals

- NEARVIA is NOT a generic full-time resume/job portal (e.g., LinkedIn, Indeed, Monster).
- NEARVIA is NOT a black-box opaque AI platform.
- NEARVIA does not manage permanent long-term payroll contracts.
