# NEARVIA Domain Glossary

| Term                     | Definition                                                                                                |
| :----------------------- | :-------------------------------------------------------------------------------------------------------- |
| **Worker**               | An individual available for short-duration, flexible, local tasks, shifts, or daily-wage opportunities.   |
| **Job Provider**         | A business, shop, contractor, restaurant, event organizer, or individual offering short-duration work.    |
| **Agent**                | A verified local intermediary assisting workers who have limited digital literacy or smartphone access.   |
| **Admin**                | Platform operator overseeing trust verification, dispute arbitration, moderation, and system health.      |
| **Hyperlocal**           | Proximity-bounded search and matching confined by default to an approximate 5 km radius.                  |
| **Available-Now**        | Real-time worker availability state indicating readiness to accept immediate local work assignments.      |
| **Micro-Task**           | High-urgency work lasting between 1 and 2 hours (e.g. loading boxes, retail stocking, quick repairs).     |
| **Short Shift**          | Temporary work engagement lasting 3 to 6 hours (e.g. restaurant helper, event staff).                     |
| **Explainable Matching** | A transparent, multi-factor ranking formula that exposes measurable reasons for match scores.             |
| **PostGIS Geography**    | Spatial data type representing earth-curvature WGS84 points (`GEOGRAPHY(Point, 4326)`) indexed with GIST. |
| **Assignment**           | The active contractual execution state binding an accepted worker to a specific job post.                 |
| **Dispute**              | Formal conflict resolution ticket raised when task scope, arrival, or compensation is contested.          |
